*Section: Managing module content*

Module dependencies should be documented in the package metadata.

## Practical check

Inspect MdBlog `package.json` and its `dependsOn` field; verify that dependent packages are installed and compatible.

For implementation details, compare the [MdBlog reference module](https://github.com/adedayoAdetunji/MdBlog) with the [Core Services guides](../appcore/README.md).
