# Accessing Modules Development

[Previous](module-development-overview.md) · [Main documentation](../README.md) · [Guide contents](README.md) · [Next](module-development-conventions.md)

*Section: Getting started*

Open the LifeTechOCMS administration interface and navigate to the module-development or module-management area. The exact menu label and permissions depend on the installed release.

Use the module development interface to create packages, manage content and access Auto Create. Confirm your account has the necessary development permissions before proceeding.

For screenshots and release-specific controls, consult the [earlier UI guide](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/accessing-modules-development.md).
