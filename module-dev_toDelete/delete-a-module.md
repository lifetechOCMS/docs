# Delete a Module

[Previous](install-a-module.md) · [Main documentation](../README.md) · [Guide contents](README.md) · [Next](security-and-management-permissions.md)

*Section: Deployment and maintenance*

Delete a module only after confirming it is no longer needed.

## Practical check

Back up module resources and relevant `tb_` tables, review dependencies, and confirm how the installed release handles data on deletion.

For implementation details, compare the [MdBlog reference module](https://github.com/adedayoAdetunji/MdBlog) with the [Core Services guides](../appcore/README.md).
