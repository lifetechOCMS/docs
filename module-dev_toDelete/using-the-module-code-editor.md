*Section: Managing module content*

The module code editor lets developers work on module content within LifeTechOCMS.

## Practical check

Open a module resource, make a small change, save it, and confirm the file and package reflect the change.

For implementation details, compare the [MdBlog reference module](https://github.com/adedayoAdetunji/MdBlog) with the [Core Services guides](../appcore/README.md).
