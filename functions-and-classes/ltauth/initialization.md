# Initialization

[Previous](ltauth.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](authentication-methods.md)

The class can be instantiated normally or re-initialized statically. It automatically sets the internal user model to TbUser.

```
// Standard initialization
$auth = new LtAuth();
 
// Static re-initialization of the internal user model
LtAuth::hidInitiate();
```

Source: https://www.lifetech.host/hubs/Docs#initialization
