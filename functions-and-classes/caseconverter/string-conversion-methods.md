# String Conversion Methods

[Previous](caseconverter.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](database-array-conversion-methods.md)

These methods take a single string as an argument and return the formatted string. Because they are static, you do not need to instantiate the class to use them.

- **snakeToCamel($string)** Converts a snake_case string to camelCase. *Example:* user_first_name:â userFirstName
- **pascalToSnake($string)** Converts a PascalCase string to snake_case. *Example:* UserFirstName : user_first_name
- **camelToSnake($string)** Converts a camelCase string to snake_case. *Example:* userFirstName: user_first_name
- **snakeToPascal($string)** Converts a snake_case string to PascalCase. *Example:* user_first_name:  UserFirstName
- **pascalToCamel($string)** Converts a PascalCase string to camelCase. *Example:* UserFirstName: userFirstName
- **camelToPascal($string)** Converts a camelCase string to PascalCase. *Example:* userFirstName: UserFirstName
