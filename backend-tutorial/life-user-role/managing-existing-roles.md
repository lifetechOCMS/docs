# Managing Existing Roles

[Previous](adding-a-new-role.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](assigning-role-permissions.md)

Available actions for managing roles include:Edit Role: Modify the role's name or core settings.Enabled/Disabled toggling: Quickly activate or deactivate an entire role group. Delete Role: Permanently remove the role from the system.                    

 ![Managing Existing Roles screenshot](https://www.lifetech.host/hubs/packages/modules/MdDocs/Media/6dd3dea2ba6e4164b11c58e862794526.png)

Permission button: Access the granular privilege settings for the specific role.
