# View Page Details

[Previous](edit-page.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](delete-page.md)

This action allows you to inspect the full configuration and metadata of a page without risking accidental edits. 

**Steps:**

1. Find the target page in the management table. 
1. Click the **View Page Details** action icon. 
1. A dialog box or window will appear displaying the page's properties, routing information, and assigned modules.
1. Close the details view when you are finished reviewing the information

Source: https://www.lifetech.host/hubs/Docs#view-page-details
