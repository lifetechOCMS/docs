# Life Page Interface

[Previous](lifepage.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](adding-a-new-page.md)

**Steps:**

1. From the left sidebar navigation, expand the **Content** section.
1. Select **Life Page.**

The main interface provides quick-action tools for page management:

- **Add Page:** Click to open the dialog box to create a new page.
- **Publish to Content:** Click to open the publish page to content dialog box.
- **Edit Route:** Click to edit the assigned route path.
- **View Region:** Click to open the assigned theme dialog box.
- **Publish Route** Click to open the Publish Api page to one more route dialog box.
- **View Page:** Click to preview or view the live page.
- **Toggle Publish:** Click to toggle the page's Publish status.
- **Edit Page:** Click to change some
- **View Page Details:** Click to preview page details
- **Delete Page:** Click to delete page permanently
