# View region

[Previous](edit-route.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](view-page.md)

This allows pages to view default themes assign to it and to publish and unpublish

**Steps:**

1. Select the page you wish to style.
1. Click the **View region** action. 
1. The system will open the default theme published for the page dialog box.
1. Publish and Unpublish theme region for the page
