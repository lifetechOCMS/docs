# Accessing the File Manager

[Previous](file-manager.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](life-media.md)

**Steps:**

1. Look at your left sidebar navigation and click on **Structure** to expand the menu.
1. Click on **File Manager**.
1. Once you open the page, you will notice two main tabs at the top: **File Manager** (for general files) and **Life Media** (for branding)
