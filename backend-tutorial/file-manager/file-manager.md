## Overview

The File Manager acts as the built-in directory system for the LIFETECH OCMS. It allows technical users to browse, upload, modify, and delete system files, media assets, and structural folders directly from the backend without needing external tools.

Source: https://www.lifetech.host/hubs/Docs#file-manager
