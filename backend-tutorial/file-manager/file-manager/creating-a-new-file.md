# Creating a New File

[Previous](file-manager.md) · [Main documentation](../../../README.md) · [Guide contents](README.md) · [Next](uploading-files.md)

When you click the **New File** button in the top navigation bar, a "Create New File" window will pop up.

To make things easier and prevent naming errors, the system purposefully separates the file's name from its file extension (the type of file it is). Here is how to fill it out:

- **File Name:** Type the actual name you want to give your new file (for example, `about-us` or `custom-styles`).

**%%Do not** type the file extension (like `.html` or `.css`) in this box! Just type the base name.%%

- **File Type:** Click the dropdown menu to select the exact kind of file you want to create. The system supports standard web and data formats, including:
- **HTML** (Web page structure)
- **CSS** (Styling and design)
- **JS** (JavaScript for interactivity)
- **PHP** (Server-side code)
- **TXT** (Plain text)
- **JSON** (Data formatting)
- **XML** (Data storage)
- **MD** (Markdown for text formatting)

**How it works:** Once you type a name like `about-us` and select `HTML` from the dropdown, the system will automatically combine them and create the file as `about-us.html` in your directory.

Source: https://www.lifetech.host/hubs/Docs#creating-a-new-file
