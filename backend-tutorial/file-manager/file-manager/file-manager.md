# File Manager

Previous · [Main documentation](../../../README.md) · [Guide contents](README.md) · [Next](creating-a-new-file.md)

This tab displays your website's directory (Files and Folders). By default, you start in the "Root" (the main, top-level folder).

**Top Navigation Bar Actions:** At the top right of the file list, you have your main creation tools:

- **Root (Home icon):** Click this to instantly jump back out of any sub-folders and return to the main starting directory.
- **New Folder:** Creates a new, empty folder in your current location to help you organize your files.
- **New File:** Creates a brand-new, blank file.
- **Upload:** Opens a prompt allowing you to select files from your computer and upload them directly into the folder you are currently viewing.

 
                 
                 ![File Manager screenshot](https://www.lifetech.host/hubs/packages/modules/MdDocs/Media/cb39a2863b860968b304aa57f1f49a11.png)
            
            

**Row Actions (The Icons):** Next to every file and folder in the list, you will see a row of colorful icons. Here is what they do:

- **Rename (Pencil icon):** Click this to change the name of the file or folder.
- **Download (Arrow pointing down):** Saves a copy of the item to your computer. Individual files will download normally, but if you click this on a folder, the system will conveniently compress the whole folder into a `.zip` file for you.
- **Edit / Open (Folder or Edit icon):** * If you click this on a **folder**, it will navigate *into* that directory so you can see what is inside.
- If you click this on a **file**, it will open an editing box right on your screen so you can view or change the code/text inside it.
- **Delete (Trash Can icon):** Permanently removes the file or folder from the system. Be careful, as this cannot be undone!
