# Uploading Files

[Previous](creating-a-new-file.md) · [Main documentation](../../../README.md) · [Guide contents](README.md) · Next

The File Manager includes a powerful, user-friendly upload tool that allows you to add files from your computer directly into your website's directory.

When you click the **Upload** button in the top navigation bar, the "Upload File" window will appear. This tool is designed to save you time by supporting **multiple file uploads at once** and offering two simple ways to add your files:

**Method 1: Drag and Drop (Fastest)**

1.     Open a folder on your computer containing the files you want to upload.

2.     Click and highlight one or more files.

3.     Drag those files directly over the dotted box in the browser window that says *"Drag and drop files here"* and release your mouse button.

**Method 2: Click to Browse**

1.     Click the blue Browse Files button inside the dotted box.

2.     Your computer's file explorer will open.

3.     Select the files you want to upload. *(Tip: You can hold down the *`*Ctrl*`* key on Windows or the *`*Command*`* key on Mac to select multiple files at the same time!)*

4.     Click "Open" to add them to the tool.

**Reviewing and Finishing the Upload:** 

Once you have dragged or selected your files, they will not upload instantly. Instead, they will queue up in a list below the drop zone (showing the file name and size). This gives you a chance to review what you are about to add.

When you are ready, simply click the solid blue **Upload** button at the bottom of the window to process and save all the files in your queue to the File Manager simultaneously.
