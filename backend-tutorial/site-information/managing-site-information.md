**Steps:**

 From the left sidebar navigation, expand the Lifetech section. Click on Site Information.

The interface will display a table with the current website information. You can perform the following actions:

**Edit Info:** Click the edit icon to modify the site's branding, text, or social links.

**View Info Details**: Click the view (eye) icon to preview the configured information. 

Lifetech OCMS provides a suite of global helper functions for developers to call on, to make the site information available. click [LtSiteInfo and Helper functions](../../functions-and-classes/ltsiteinfo-and-site-helper-functions/ltsiteinfo-and-site-helper-functions.md) to read more.
