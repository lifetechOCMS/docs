# Adding a New User

[Previous](user-management-interface.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](managing-existing-users.md)

**Steps:**

1. Click the **+ Add User** button in the top right corner of the dashboard.
1. The **Add New User** dialog box will appear.
1. Fill in the required personal details: Surname, Firstname, Othername, and Phone Number.
1. Provide the login credentials: Username and Email.
1. Select the account **Status** (e.g., Enabled).
1. Set the user's password. You can manually type it into the **Password** and **Confirm** fields, or click the key icon to auto-generate a secure password.
1. Assign one or more **Role(s)** by checking the relevant boxes (e.g., Anonymous, Developer, Lecturer).
1. Click **Add** to create the user.
