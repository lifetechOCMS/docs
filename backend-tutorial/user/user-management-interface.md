# User Management Interface

[Previous](user.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](adding-a-new-user.md)

**Steps:**

1. From the left sidebar navigation, expand the **Users** section.
1. Click on **Life User**.

The main workspace displays a data table of all registered users. The table provides the following columns for quick overview:

Firstname | Email | Username | User Role | Last Access | Created At | Actions
