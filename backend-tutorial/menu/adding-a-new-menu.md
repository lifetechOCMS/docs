# Adding a New Menu

[Previous](menu-management-interface.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](editing-an-existing-menu.md)

**Steps:**

1. Click the **+ Add Menu** button in the top right corner.
1. The **Add New Menu** dialog box will appear.
1. Fill in the required details:

- **Menu Name:** Enter the display name for the navigation link.
- **Page:** Select the target page or route from the dropdown list.
- **Level:** Choose whether this is a "1 - Parent Menu" or a subordinate level.
- **Target View:** Define how the link behaves when clicked (e.g., _Self - Open on the same frame or tab).
- **Icon:** Enter the relevant Font Awesome class (e.g., fas fa-play) to display an icon next to the menu text.

	  4. Click **Add** to save and create the menu item.
