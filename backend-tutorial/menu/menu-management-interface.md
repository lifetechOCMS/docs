# Menu Management Interface

[Previous](menu.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](adding-a-new-menu.md)

**Steps:**

1. From the left sidebar navigation, expand the **Structure** section.
1. Click on **Menu Management**

The main workspace displays a table of all existing menu items. The table provides a quick overview of:

- **Menu:** The display name of the menu item.
- **Route Path/Page:** The associated URL route or specific page linked to the menu item.
- **Level:** Indicates the hierarchy level (e.g., Level 1 for Parent Menus, Level 2 for Sub-menus).
- **Role/Permission Indicators:** Checkboxes indicating which user groups (e.g., Services, Anonymous, Developer, Lecturer) have access to view the menu item.
- **Actions:** Quick links to Edit or Delete the specific menu entry.
