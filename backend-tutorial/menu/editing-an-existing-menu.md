# Editing an Existing Menu

[Previous](adding-a-new-menu.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · Next

**Steps**:  

Locate the menu item in the data table.Click the Edit (pencil) icon under the Actions column. The Edit Menu dialog box will open.If you change the Level to a sub-menu (e.g., 2 - Submenu Under Level 1), a new Parent dropdown field will appear, allowing you to nest the current item under an existing Parent menu.Update any other necessary fields, such as the Target View (e.g., _Blank - Open new window or tab) or the Icon (e.g., fas fa-sign-in-alt).Click Update to save your modifications.

Source: https://www.lifetech.host/hubs/Docs#editing-an-existing-menu
