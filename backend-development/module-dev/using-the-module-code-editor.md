# Using the Module Code Editor

[Previous](manage-authentication-sessions-and-permissions.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](edit-or-update-existing-module-content.md)

*Section: Managing module content*

Use the module code editor to open and modify the source files belonging to the selected module. Save changes and verify that the updated code is reflected in the module runtime.

For the documented UI workflow, see the existing [Coding Editor guide](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/coding-editor.md). Keep PHP namespaces and class names consistent with the file being edited.
