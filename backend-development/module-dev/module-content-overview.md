# Module Content Overview

[Previous](deleting-a-module.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](add-new-module-content.md)

The **Module Package Content** area allows you to:

- Create new module content
- Updates existing content
- Run/Preview content 
- Open the coding editor
- Export a module package
- Automatically create Model / Controller / Service files

This section explains each feature step-by-step.

**Steps:**

1. Select/click any of the registered module package to redirect to its content page
