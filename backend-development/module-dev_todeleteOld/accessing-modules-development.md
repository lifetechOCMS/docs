# Accessing Modules Development

[Previous](module-development.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](adding-a-module-package.md)

**Steps:**

1. Navigate to Packages from left sidebar.
1. Select Modules Development

	 ![Accessing Modules Development screenshot](https://www.lifetech.host/hubs/packages/modules/MdDocs/Media/83bacce294182261cd3f1aaa66ee35e6.png)

The interface contains:

- Module list table
- Add Module button
- Publish/Unpublish toggle
- Install Module
- Delete action 
- Edit action
