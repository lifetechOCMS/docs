# Module Content and Resource Types

[Previous](understand-module-folders-and-subfolders.md) · [Main documentation](../README.md) · [Guide contents](README.md) · [Next](add-new-module-content.md)

*Section: Getting started*

Module content includes PHP Models, Controllers, Services, route definitions, and Views. Supporting resources may also be present in the package.

For a blog-category feature, identify `Models/TbBlogCategory.php`, `Controllers/TbBlogCategoryController.php`, `Services/TbBlogCategoryService.php` and `Services/MdBlogRoutes.php` in [MdBlog](https://github.com/adedayoAdetunji/MdBlog).

The [earlier module-content guide](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/module-content-overview.md) provides UI-specific instructions.
