# Module Development Overview

Previous · [Main documentation](../README.md) · [Guide contents](README.md) · [Next](accessing-modules-development.md)

*Section: Getting started*

A **LifeTechOCMS module** adds application functionality using a named package, database Models, Controllers, Services, Views and routes. This guide uses **MdBlog** as its practical reference.

## What you will learn

- Create a module package with a PascalCase name beginning with `Md`.
- Follow the compulsory `tb_` table naming convention.
- Connect Models, Controllers and Services using consistent names.
- Register endpoints through the module's automatically generated route file.
- Work with Core Services and test module operations.

## Example

`MdBlog` contains `TbBlogCategory`, `TbBlogCategoryController`, `TbBlogCategoryService` and `MdBlogRoutes.php`. See the [MdBlog repository](https://github.com/adedayoAdetunji/MdBlog).
