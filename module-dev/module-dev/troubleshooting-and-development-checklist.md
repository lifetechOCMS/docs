*Section: Deployment and maintenance*

Use this checklist before publishing a module.

## Practical check

Verify PascalCase `Md` module naming, `tb_` table prefixes, Model-derived Controller and Service names, automatically generated routes, permissions, dependencies, API responses, and documentation links.

For implementation details, compare the [MdBlog reference module](https://github.com/adedayoAdetunji/MdBlog) with the [Core Services guides](../appcore/README.md).
