Synchronize module resources when changes are made through the editor or filesystem.

## Practical check

Check that `Models/`, `Controllers/`, `Services/` and `Views/` match the expected package state after synchronization.

For implementation details, compare the [MdBlog reference module](https://github.com/adedayoAdetunji/MdBlog) with the [Core Services guides](../appcore/README.md).
