# Add New Module Content

[Previous](module-content-and-resource-types.md) · [Main documentation](../README.md) · [Guide contents](README.md) · [Next](auto-create-model-controller-service.md)

*Section: Creating module components*

Use the module-development interface to create a resource of the appropriate type in the appropriate location.

For a new `tb_student` table, use `Models/TbStudent.php`, `Controllers/TbStudentController.php` and `Services/TbStudentService.php`. Each filename must match its PHP class name.

See the [earlier UI instructions](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/add-new-module-content.md) for release-specific controls.
