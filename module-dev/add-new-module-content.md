# Add New Module Content

[Previous](module-content-and-resource-types.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](auto-create-model-controller-service.md)

*Section: Creating module components*

Create the desired module content in the module-development interface. Select the correct type and location so it matches the package's MVC structure.

## Example

For a category feature in `MdBlog`, the related files are `Models/TbBlogCategory.php`, `Services/TbBlogCategoryService.php`, and `Controllers/TbBlogCategoryController.php`.

See the [existing Add New Module Content instructions](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/add-new-module-content.md) for the interface steps.
