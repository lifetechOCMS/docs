*Section: Practical MdBlog development*

The MdBlog repository provides a complete worked example of the module layers:

| Layer | Example |
| --- | --- |
| Model | `Models/TbBlogCategory.php` |
| Service | `Services/TbBlogCategoryService.php` |
| Controller | `Controllers/TbBlogCategoryController.php` |
| Route | `Services/MdBlogRoutes.php` |
| View | `Views/Category.html` |

Start with the route for `/blogs/categories`, then follow the controller, service, and model. The view is the user-facing integration point.

[Explore MdBlog](https://github.com/adedayoAdetunji/MdBlog).
