*Section: Getting started*

In the existing LifeTech guide, the process is: **Add Module Package**, complete the required fields, and **Submit**.

## Example metadata

MdBlog uses a `package.json` file containing `packageName`, `packageType`, `version`, and `dependsOn`. Inspect its actual [package.json](https://github.com/adedayoAdetunji/MdBlog/blob/main/package.json) before adapting the values.

For the original screenshots and UI instructions, see [Adding a Module Package](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/adding-a-module-package.md).
