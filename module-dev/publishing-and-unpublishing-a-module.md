# Publishing and Unpublishing a Module

[Previous](configure-module-dependencies.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](understand-the-mdblog-mvc-structure.md)

*Section: Managing module content*

Publishing controls whether a module is made available in the LifeTech installation. Before publishing, verify routes, required database tables, permissions, and package dependencies.

For the administrative steps, consult the existing [Publishing / Unpublishing a Module guide](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/publishing-unpublishing-a-module.md). Do not confuse publishing a package with publishing an individual theme view.
