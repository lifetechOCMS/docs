# Edit or Update Existing Module Content

[Previous](using-the-module-code-editor.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](sync-module-files.md)

*Section: Managing module content*

Identify the module, locate the content item, and update the intended file without changing unrelated package resources.

## Practice

Open the category controller and trace `index()` to its service method before changing either file. This reduces the risk of editing the wrong layer.

The original [Updating Existing Content guide](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/updating-existing-content.md) provides the UI-specific workflow.
