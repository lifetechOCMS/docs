# Module Development Overview

Previous · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](accessing-modules-development.md)

*Section: Getting started*

A LifeTech OCMS module adds application functionality using module packages. This learning path follows the MVC organization found in **MdBlog**, with models, controllers, services, views, route definitions, and package metadata.

## Learning outcome

By the end, you should be able to identify each module component, follow a request through the application, test an API endpoint, and manage the package lifecycle.

## Reference implementation

The [MdBlog repository](https://github.com/adedayoAdetunji/MdBlog) is the worked example throughout these lessons. The framework services are documented in [Core Services (MdLt)](../../appcore/README.md).
