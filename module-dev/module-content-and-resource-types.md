# Module Content and Resource Types

[Previous](understand-module-folders-and-subfolders.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](add-new-module-content.md)

*Section: Getting started*

Module content includes the source files used to implement functionality, such as PHP controllers, models, services, and HTML views. The MdBlog repository also includes JavaScript and CSS assets within `Services/`.

## Learning task

Open the `Controllers/`, `Models/`, `Services/`, and `Views/` directories in MdBlog. Identify one file in each directory and describe its responsibility.

The existing UI-focused [Module Content Overview](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/module-content-overview.md) remains the reference for content-management operations.
