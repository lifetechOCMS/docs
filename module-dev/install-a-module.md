# Install a Module

[Previous](export-module-package.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](delete-a-module.md)

*Section: Deployment and maintenance*

Install the module using the LifeTech module-management workflow and ensure that declared dependencies are available.

## Checks

- The package is recognized as a module.
- Required tables and resources are present.
- Routes resolve to the intended controllers.
- Permissions and required configuration are set.

See [Installing a Module](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/installing-a-module.md) and [MdBlog's installation notes](https://github.com/adedayoAdetunji/MdBlog#installation).
