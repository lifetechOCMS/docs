# Create Module Views

[Previous](define-module-routes-and-endpoints.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](connect-views-to-module-apis.md)

*Section: Creating module components*

MdBlog contains HTML views including `Blog.html`, `Category.html`, `Manage-post.html`, and `Admin-dashboard.html`.

Views present module data to the user. Keep business operations in services and use API calls for data exchange where the view requires dynamic records.

Explore the [MdBlog Views directory](https://github.com/adedayoAdetunji/MdBlog/tree/main/Views). The exact template loading and dispatch rules should be checked against your LifeTech installation.
