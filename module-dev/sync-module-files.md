# Sync Module Files

[Previous](edit-or-update-existing-module-content.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](configure-module-dependencies.md)

*Section: Managing module content*

Module source files may be edited inside the LifeTech interface or maintained as repository files. Before synchronizing, identify which copy is authoritative and back up local edits.

## Verification checklist

- Compare the source and destination files.
- Confirm that the package and namespaces remain unchanged.
- Recheck routes after synchronizing controller or service files.
- Test the affected endpoints.

**Implementation note:** The exact module file-sync controls have not been verified in the inspected repositories; use your installed LifeTech version's supported workflow.
