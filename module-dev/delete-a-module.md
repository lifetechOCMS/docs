# Delete a Module

[Previous](install-a-module.md) · [Main documentation](../../README.md) · [Guide contents](README.md) · [Next](security-and-management-permissions.md)

*Section: Deployment and maintenance*

Before deleting a module, export or back up resources you need to retain. Check whether its routes, pages, menus, or database records are still used elsewhere.

The original [Deleting a Module guide](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/deleting-a-module.md) describes the administrative operation. Do not assume that deleting a package automatically removes all related database records.
