*Section: Deployment and maintenance*

When editing package metadata, preserve the package name, type, and dependency declarations unless you intend a compatible migration.

For the existing UI process, consult [Editing a Module](https://github.com/lifetechOCMS/docs/tree/master/backend-development/module-dev/editing-a-module.md). Re-test installation and route loading after changing metadata.
